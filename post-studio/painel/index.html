        Formato de cada tipo de template
        
passos / lista / checklist / mito:  "itens": [{ "emoji": "✨", "titulo": "...", "texto": "..." }]
  (emoji só em "lista"; em "mito", titulo = mito e texto = verdade)
comparativo:  2 itens; o "texto" de cada coluna separa linhas com |
capa / citacao:  só "titulo" (lista de linhas) e "subtitulo"
Opcional em qualquer um: "kicker", "subtitulo", "destaque": { "forte": "...", "texto": "..." },
  "tema" (escuro | claro | primaria | secundaria), "tamanhoTitulo" (px), "legenda" (senão é montada pelos modelos)
datas: "data": "MM-DD" (todo ano) ou "AAAA-MM-DD" (uma vez)
