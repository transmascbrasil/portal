Configurações

Fica guardado só neste navegador (o login protege o painel, mas o token continua salvo aqui até você remover). Crie em GitHub → Settings → Developer settings → Fine-grained tokens: escolha só este repositório e as permissões Contents: Read and write e Actions: Read and write. Não use em computador compartilhado.

Crie a chave em console.anthropic.com. A API é cobrada por uso, separada do plano do claude.ai (em geral poucos centavos de dólar por post). Defina um limite mensal de gasto no Console e use uma chave só para este painel.

Crie a chave grátis em aistudio.google.com/apikey (precisa de conta Google). O plano gratuito tem limite de uso por minuto e por dia, e o Google pode usar o que for enviado para melhorar os produtos dele, então não envie dados pessoais. Se der erro de modelo, veja o nome atual no AI Studio e troque aqui.

Exemplos: Groq (https://api.groq.com/openai/v1) e OpenRouter (https://openrouter.ai/api/v1, com modelos que terminam em :free). Os modelos gratuitos mudam com frequência: confira o nome e os limites no site do serviço. Esses modelos costumam errar mais em português e em seguir as regras do projeto, então leia tudo com atenção.

As chaves ficam só neste navegador e são enviadas apenas para o serviço escolhido.
🔁 Repostar

Cada repostagem é uma cópia, com data própria no histórico. Depois você pode editar o texto e mudar a ordem na aba Fila. Lembre de conferir se contatos, convênios e números ainda estão atuais.
🗓 Programar publicação

O robô confere a cada 30 minutos, das 7h às 23h30. O post sai no primeiro horário depois do que você escolher, então pode atrasar alguns minutos (às vezes mais, quando o GitHub está cheio). Programar já aprova o post. Se já houver um post publicado no mesmo dia, o horário regular daquele dia é pulado para não sair dois no dia.
